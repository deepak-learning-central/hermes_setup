01

Connect a model

The Pi runs the assistant. Your provider runs the model, so no large model download is needed. Enter a model your account can access.

For another provider, use its OpenAI-compatible endpoint and model ID. A provider account and available credit may be required.

02

Connect messaging channels

Optional: chat with Hermes through Telegram, Discord or Slack. Enable the channels you want and enter their credentials and your user ID.

Create a bot with @BotFather (/newbot). Enter your numeric Telegram user ID, not your username. After setup, open your bot and send /start. Setup guide ↗

Use commas for multiple user IDs. Only these users should be allowed to use your assistant.

Create a Discord bot, enable Message Content Intent and invite it to your server with messaging permissions. Enable Developer Mode to copy your numeric user ID. Setup guide ↗

Use commas for multiple user IDs. Only these users should be allowed to use your assistant.

Create and install a Slack app with Socket Mode, required bot scopes and event subscriptions. Copy your Slack Member ID from your profile. Setup guide ↗

Use commas for multiple user IDs. Only these users should be allowed to use your assistant.

Bot/app creation and permissions must be completed in the messaging service. Setup saves and applies these settings; verify each channel by sending your bot a message afterwards. Disabling a channel clears its saved credentials on your next setup run.

03

Protect your settings

Keep this passphrase to reopen your saved settings. Docker also needs runtime credentials; generated deployment files are private to your Pi user.
